# P0.3 — `breakerbox claudecode init`: install Claude Code hooks (session + daily ceilings)

**Vision:** [VISION.md](../VISION.md) §7 · Phase 0. **Issue:** [#152](https://github.com/Amitcoh1/agentbreaker/issues/152).

Principle §3.4 — **enforcement lives in the execution path.** Claude Code hooks are a trip point
AgentBudget/Alephant don't have (risk §11: move fast here). Honors repo constraints: **codegen-only,
no server, no stored keys** — we emit hooks the user runs.

## Scope (thinnest slice)
`breakerbox claudecode init` — one command that wires Breakerbox enforcement into the user's Claude
Code via hooks in `.claude/settings.json`.

- New CLI subcommand dispatched in `cli.py`.
- Installs three hooks: **UserPromptSubmit** budget check, **PreToolUse** trip on `Task`/`Bash` near
  ceiling, **Stop** reconciliation of the session ledger.
- **Session** and **daily** ceilings, configurable via flags (with sane defaults).
- Optional `--otel` flag: wire spend export to a local OTel collector.
- Idempotent: re-running merges/updates the Breakerbox hooks without duplicating existing user hooks.

## Acceptance criteria
- [ ] `breakerbox claudecode init` writes/merges valid `.claude/settings.json` with the 3 hooks.
- [ ] `--session-ceiling` / `--daily-ceiling` flags set the enforced ceilings; defaults documented.
- [ ] Re-running is idempotent (no duplicate hooks; preserves unrelated user hooks).
- [ ] `--otel <endpoint>` (optional) adds local-collector export wiring.
- [ ] Generated hook scripts run standalone (codegen-only; no Breakerbox server call, no key storage).
- [ ] Self-check/golden: generated settings.json parses as valid JSON with the 3 hooks; a test asserts
      the budget-check hook blocks a prompt once the session ceiling is exceeded.
- [ ] `.venv/bin/ruff check src tests && .venv/bin/pytest -q` green.

## Out of scope (phase gate)
No hosted ingestion, no multi-tenant reconciliation — OTel wiring targets a *local* collector only.
Server-side/gateway enforcement is Phase 3 (P3.1).
