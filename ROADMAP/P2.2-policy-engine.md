# P2.2 — Policy engine v1

**Issue:** [#156](https://github.com/Amitcoh1/agentbreaker/issues/156)

**Vision:** VISION.md §7 · Phase 2 · **P2.2**. Realizes §6 **POLICY ENGINE**.

## Scope
A rule engine over the ledger that compiles declared budgets into enforcement decisions:
- **Budgets, ceilings, degradation ladders** (reuse the P0.1 ladder primitive).
- **Scheduled resets** (daily/weekly/monthly).
- **Per-dimension scoping** (per tenant / project / agent / model, etc.).
- **Anomaly & trajectory rules** — token-rate signatures, stuck-loop shapes (healthy agents pause for I/O; sustained high-velocity burn with no progress is a loop signature).

## Definition of done
- [ ] Policies compile to deterministic ALLOW / DEGRADE / TRIP decisions on the fast path (<1ms).
- [ ] Scoping + scheduled resets work per-dimension.
- [ ] Ladders from P0.1 are expressible as policy.
- [ ] At least one trajectory/anomaly rule (stuck-loop signature) fires in tests.

## Phase gate
Phase 2 (co-founder gated). Depends on P2.1 (ledger). Feeds the NL builder (P2.3), which compiles text into these rules.
