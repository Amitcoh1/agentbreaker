# P2.3 — NL policy builder v1

**Issue:** [#157](https://github.com/Amitcoh1/agentbreaker/issues/157)

**Vision:** VISION.md §7 · Phase 2 · **P2.3**. Realizes §6 **NL POLICY BUILDER** + principle §3.6 (policies belong to humans, not YAML).

## Scope
Text → compiled rule → human-readable preview → deploy on confirmation. E.g. *"cap research agents at $50/day per tenant, alert me at 80%, kill any single run over $5."*

- Parse NL intent into a **P2.2 policy object**.
- Show a **preview** of exactly what will be enforced (thresholds, scope, ladder) before deploy.
- Deploy on confirmation; **instrument usage** to answer open-question §10.4 (genuinely used vs. demo candy).

## Definition of done
- [ ] A natural-language budget compiles to a valid policy engine rule.
- [ ] The preview accurately describes the enforcement that will result.
- [ ] Deploy is gated on explicit confirmation.
- [ ] Usage is instrumented (created / edited / kept vs. abandoned).

## Phase gate
Phase 2 (co-founder gated). Ship **thin but real**; the vision flags this as measure-then-decide, not a big build. Depends on P2.2.
