# P3.5 — Observability partnerships

**Issue:** [#165](https://github.com/Amitcoh1/agentbreaker/issues/165)

**Vision:** VISION.md §7 · Phase 3 · **P3.5**. Realizes §6 key decision: *every adapter emits the same OTLP-compatible event schema.* Partners, not competitors (§4).

## Scope
Ingest/export with the observability players (Langfuse / Helicone / LangSmith / Datadog / CloudWatch):
- **Ingest** their spend/usage telemetry into the ledger.
- **Export** Breakerbox enforcement events out via OTLP.
- Every integration cements the category and makes us complementary to read-only tools.

## Definition of done
- [ ] Breakerbox events export via OTLP to at least one observability backend.
- [ ] At least one observability source can be ingested into the ledger.
- [ ] The shared schema is OTLP-compatible end to end (this is the contract behind P2.1 + P3.3).

## Phase gate
Phase 3 (+10 → +18mo). The OTLP schema itself is foundational (defined in P2.1); this item is the two-way integrations on top.
