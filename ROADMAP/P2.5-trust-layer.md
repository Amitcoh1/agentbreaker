# P2.5 — Trust layer v1

**Issue:** [#159](https://github.com/Amitcoh1/agentbreaker/issues/159)

**Vision:** VISION.md §7 · Phase 2 · **P2.5**. Realizes §6 **TRUST LAYER**. Guardrail metric (§9): false-trip rate — trust, once lost, doesn't come back.

## Scope
The org-wide version of the P0.2 shadow primitive:
- **Org-wide shadow mode** (roll a policy out observe-only across all tenants/projects).
- **Trip audit trail** — every enforcement decision is a durable, explainable record.
- **Override with reason-capture** — a human can override a trip; the reason is logged.

## Definition of done
- [ ] Any policy can run org-wide in shadow before enforcing.
- [ ] Every trip/would-trip is an auditable record with its explanation object.
- [ ] Overrides are permitted and captured with a required reason + actor + timestamp.
- [ ] False-trip rate is measurable from the audit trail.

## Phase gate
Phase 2 (co-founder gated). Generalizes P0.2. Depends on P2.1 (ledger) + P2.2 (policy engine).
