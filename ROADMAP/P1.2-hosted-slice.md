# P1.2 — Thin hosted slice for design partners

**Issue:** [#154](https://github.com/Amitcoh1/agentbreaker/issues/154)

**Vision:** VISION.md §7 · Phase 1 · **P1.2**. Realizes §6: the first real slice of **Adapters → Ledger → live spend view → enforced policy**. Roadmap: `ROADMAP/P1.2-hosted-slice.md`.

Principle §3.3 — shadow mode first, then graduate to enforcement. This is the **proof-of-demand vehicle**: the thing 3–5 design partners actually run.

## Scope (thinnest slice)
A thin hosted slice, single-tenant per partner (not the full multi-tenant control plane yet):
- Their adapter emits spend events → a hosted **single-tenant ledger**.
- A **live spend view** (per run / agent / model).
- **One enforced policy** each, started in **shadow**, graduated to **enforce** once they trust it.

## Definition of done
- [ ] 3–5 design partners onboarded with events flowing from their real workloads.
- [ ] Live spend view renders their spend by dimension.
- [ ] Each partner has ≥1 policy that ran in shadow, then flipped to enforce.
- [ ] Trip + drift are visible and explainable in the view.

## Phase gate
Phase 1 (+6wk → +4mo). Depends on the Phase 0 wedge landing + partners sourced (P1.1 interviews). This is the seed the Phase 2 multi-tenant ledger (P2.1) generalizes. **Gate:** partners with enforcement actively ON = the company go/no-go.
