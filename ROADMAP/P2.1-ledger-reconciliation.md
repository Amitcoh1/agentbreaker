# P2.1 — Multi-tenant event-sourced ledger + reconciliation

**Issue:** [#155](https://github.com/Amitcoh1/agentbreaker/issues/155)

**Vision:** VISION.md §7 · Phase 2 · **P2.1**. Realizes §6 **LEDGER** + principle §3.5 **two-speed accounting** — the hard problem and the moat.

## Scope
- **Event-sourced ledger:** append-only spend events; budgets are **projections** over the log (audit + replay + reconciliation by construction).
- **Dimensioned:** tenant / project / user / agent / model / run / node.
- **Multi-tenant** isolation.
- **Reconciliation loop (slow path):** ingest OTel / provider billing truth, true up the fast local counter, **surface drift**.
- **Unified event schema** (OTLP-compatible) so the ledger is adapter-agnostic (see P3.5).

## Definition of done
- [ ] Spend events are append-only + replayable; budget state is a projection, never mutated in place.
- [ ] Ledger is queryable across all 7 dimensions with tenant isolation.
- [ ] Reconciliation ingests at least one billing/OTel source and reports drift (fast counter vs truth).
- [ ] The event schema is documented and OTLP-compatible.

## Phase gate
Phase 2 (+4 → +10mo). **Requires a co-founder / full-time — do not attempt solo.** The foundation the policy engine (P2.2) and FinOps views (P2.4) build on.
