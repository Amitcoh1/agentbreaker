# P3.2 — Fleet governance

**Issue:** [#162](https://github.com/Amitcoh1/agentbreaker/issues/162)

**Vision:** VISION.md §7 · Phase 3 · **P3.2**. The compliance sale.

## Scope
Fleet governance across many tenants/teams:
- **Policy inheritance** (org → team → project).
- **RBAC** + **SSO**.
- **Full audit** — who raised which ceiling, when.

## Definition of done
- [ ] Policies inherit down a hierarchy with local override.
- [ ] Role-based access controls who can view/edit/override policies.
- [ ] SSO login works for at least one IdP.
- [ ] Every ceiling change is audited (actor, before/after, timestamp).

## Phase gate
Phase 3 (+10 → +18mo). Enterprise/compliance. Depends on P2.5 (trust/audit layer).
